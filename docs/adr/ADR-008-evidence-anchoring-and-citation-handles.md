# ADR-008: Evidence anchoring, citation handles, and verification precedence

**Status:** ACCEPTED

## Context
The research input proposes citations like `【docID†Lx-Ly】` generated by "tracking which snippet was used", verification by an LLM YES/NO prompt or an NLI model, and treats "contradiction" as "answer unsupported by source". Principles B, C, G require that no citation can be fabricated and that claims be verifiable.

## Problem
Make citations unforgeable and verification trustworthy given untrusted model output.

## Decision
1. **Evidence** = immutable span in an immutable `TextLayer`, identified by `H(text_layer_id, start, end)` with a `quote_hash`; integrity re-checked at verification and by a scheduled job.
2. **Citation by handle:** the model sees `E1..En` handles for a server-built evidence pack and may emit only those; the server resolves them and renders the stored quote. Free-text citations are discarded.
3. **Verification order:** deterministic checks (anchor, version status, temporal, scope, literal grounding of numbers/dates/terms) precede model entailment; models may only lower a state or confirm one that passed deterministic checks.
4. **State vocabulary:** SUPPORTED, PARTIALLY_SUPPORTED, CONTRADICTED, INSUFFICIENT_EVIDENCE, TEMPORALLY_AMBIGUOUS. *Unsupported ≠ contradicted*; cross-version difference = change, not contradiction.
5. Line-number style locators are not used; character offsets + node labels + pages are.

**Disagreement with research input:** the citation format and the "unsupported = contradiction" conflation are replaced; LLM YES/NO is not trusted as the sole verifier.

## Alternatives considered
1. Model-written citations validated post hoc — rejected: still allows plausible-but-wrong pairing at scale.
2. Line-based anchors — rejected: unstable across parsers/versions.
3. Entailment model as sole verifier — rejected: untrusted component deciding trust.

## Tradeoffs
+ Fabrication-proof citations, reproducible audits. − Anchoring effort in parsing; offsets tied to a specific text layer (new layers create new evidence).

## Consequences
Parsers must emit stable offsets and page maps; `text_layer` is immutable; verification latency includes deterministic checks (budgeted in [performance](../performance.md)).

## Migration path
New parser → new `TextLayer`; old evidence remains valid for old answers; re-anchoring of live graph edges is a reviewed migration job.
